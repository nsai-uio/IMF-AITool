Welcome to IMF Application!

This tool helps you extract, model, and verify system information from industrial documents (PDF). Follow the steps below to process your document and explore how AI can assist in modelling system information.

API Key Configuration

Please choose a Google API key. You can either input your key or use the local key in the system environment.

File Selection

Step 1: Extract and create a hierarchical system components from the uploaded document.
Step 2: Extract relations between components and create a preliminary model.
Step 3: Verify the correctness of the prelimary model by asking verification questions to the LLM.
You can customize the model by selecting desired relations.
You can choose and convert the result to IMF file, which can be further used in the IMF Editor.
